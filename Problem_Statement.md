Problem Statement

1. Title

Freelancer Hiring Platform (Upwork-style)

2. Domain

Online Freelancing / Recruitment / Marketplace

3. Who is the User?

- Client – Posts projects, reviews proposals, hires freelancers, and manages projects.
- Freelancer – Creates a profile, searches for projects, submits proposals, and completes assigned work.
- Admin – Manages users, projects, categories, and monitors platform activities.

4. What Problem Are We Solving?

Many individuals and businesses struggle to find skilled freelancers quickly, while freelancers often find it difficult to discover genuine work opportunities. Existing solutions can be expensive or unsuitable for small businesses and students. This platform provides a secure and organized environment where clients can post projects, freelancers can submit proposals, and both parties can manage projects efficiently from one place.

5. Proposed Solution

The application will allow clients to register, create project listings, and receive proposals from freelancers. Freelancers can create professional profiles, browse projects, submit proposals, and manage their assigned work. Clients can review proposals, hire freelancers, monitor project progress, and provide ratings after completion. The platform will also include an admin dashboard for managing users, projects, and reports.

6. Core Entities / Database Tables

1. Users
2. Clients
3. Freelancers
4. Projects
5. Proposals (Bids)
6. Categories
7. Messages
8. Reviews
9. Payments
10. Notifications

7. User Roles & Permissions

Admin

- Manage users
- Manage project categories
- Monitor projects
- Handle reports and complaints

Client

- Register/Login
- Create and manage projects
- View proposals
- Hire freelancers
- Rate freelancers

Freelancer

- Register/Login
- Create profile
- Search projects
- Submit proposals
- Manage assigned projects
- View ratings and earnings

8. Success Criteria

- A client should be able to post a new project in less than 2 minutes.
- A freelancer should be able to submit a proposal in less than 1 minute.
- Clients should be able to hire freelancers and track project status successfully.
- The system should maintain secure login and role-based access.
- Users should receive email notifications for important activities such as registration, project invitations, and hiring.

9. Out of Scope

- Real payment gateway integration (only simulated payments)
- Video/audio calling
- Mobile application
- AI-based freelancer recommendation (planned for future enhancement)
- Cryptocurrency payments

10. Chosen Track

Java (Spring Boot) + MySQL
